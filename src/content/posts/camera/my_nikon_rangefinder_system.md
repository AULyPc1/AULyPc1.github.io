# 前言  
自从接触到摄影后，玩过数码的无反系统和胶片的单反系统  
但在单反系统出现之前，还有一种旁轴系统  
说到旁轴系统，很多人第一印象就是徕卡  
但很少有人知道尼康也曾有过一段旁轴的历史  
但当尼康大F单反系统问世后，凭借其优秀的机身做工以及镜头素质获得了世界的广泛认可  
所以尼康就顺应时代发展潮流，放弃了旁轴系统的开发，在单反系统领域进行探索  
  
尼康一共生产过10种类型的旁轴相机  
其中8种是上世纪五六十年代生产的，剩下2种是在21世纪初根据其原型机复刻生产的  
最早的是尼康Ⅰ型，于1948年3月正式发布  
之后一直到1960年依次推出了尼康M、尼康S、S2、SP、S3、S4、S3M机型  
  
在千禧年时，尼康复刻了S3以及复刻50mmf1.4镜头，其中银色8000台左右，黑色2000台左右  
之后在2005年，尼康复刻了SP，仅有2500台左右黑漆

本文主要介绍尼康1957年生产的SP，以及2000年复刻的S3机型  
同时介绍一些尼康旁轴S口的镜头  
:::

# Nikon SP  
尼康SP是一款专业级可换镜头的35mm旁轴相机，于1957年推出  
它是尼康自1948年推出尼康I以来旁轴相机研发的巅峰之作，并被誉为"当时最先进的旁轴相机"  
  
![](https://pic.aulypc0x0.online/data/nikon_rangefinders/nikon_rangefinder_system.webp)  
  
Nikon SP相机编号从6200000-6299999，但是最终并没有生产这么多  
因编号区间存在空缺与跳号，实际生产总数约为 22348 台  
目前已知记录的最高编号约为 6232141 左右，我这台编号为6231461，属于比较晚期生产的机型了  
  
尼康SP相机配备两个主副取景器，共提供六个焦距的取景框线  
主取景器放大倍率为1倍，取景框线对应50mm、85mm、105mm和135mm焦距  
主取景器左侧还有一个较小的副取景器，取景框线对应28mm、35mm焦距，但未进行视差校正  

这款相机采用尼康的S卡口镜头，它是在康泰时C卡口的基础上改进而来  
尼康SP的S卡口镜头和康泰时C卡口镜头在物理上兼容，但无法通过内置测距仪精确对焦，两者的法兰距相差了一两毫米
